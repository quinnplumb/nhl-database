This is a NHL database with all 32 NHL teams.

This database allows users to view the contracts of various players in the NHL

Players play for teams and have contracts with values based on their real world annual salary cap hit

Users should first download and run the NHLschema.sql file to create the schema for the database

After this, users should run the values file to fill the database with all 32 teams and a few players.

Users are then free to add or remove as many players or teams as they would like.
